# HSK Algae Cultivation — RimWorld 1.5 / 1.6

Аддон для Hardcore SK, добавляющий отдельную зону **«Водорослевое хозяйство»** для существующей культуры HSK `PlantAlgae`.

## Что добавляет

Зона предназначена только для водорослей и позволяет рисовать участок на:

- `WaterShallow` — мелководье
- `WaterMovingShallow` — подвижное мелководье
- `WaterMovingChestDeep` — подвижная вода по грудь
- `Marsh` — болото

Глубокая вода пока намеренно не добавляется. Зона поддерживает автоматический и принудительный посев, а также сбор урожая.

## SeedsPlease

`SeedsPlease` — **необязательная** зависимость. При включённом `notfood.seedsplease` мод добавляет семена водорослей. Без SeedsPlease водоросли выращиваются без семян.

## Установка и сборка

Папка мода должна лежать в `RimWorld\Mods\HSK_AlgaeCultivation_RimWorld` (название папки может быть другим).

В репозитории отдельно хранятся файлы для `1.5` и `1.6`. Для каждой версии DLL нужно собирать против `Assembly-CSharp.dll` соответствующей установки RimWorld.

Для RimWorld/HSK 1.6, установленной в `D:\Games\RimWorld`, открой CMD в папке мода и выполни:

```cmd
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Сборка создаст `1.6\Assemblies\HSKAlgaeCultivation.dll`. Важно: если код менялся, этот DLL нужно проверить в игре 1.6 перед публикацией.

Для RimWorld 1.5 можно собирать с `RIMWORLD_VERSION=1.5`. Если переменная версии не задана, скрипт по умолчанию собирает для 1.5.

## Проверка

1. Включить Hardcore SK и HSK Algae Cultivation.
2. Создать или загрузить колонию и выбрать меню «Зоны».
3. Выбрать «Водорослевое хозяйство» и нарисовать зону на мелководье.
4. Убедиться, что при выборе зоны отображаются команды управления, включая удаление зоны.
5. Проверить автоматический/принудительный посев, созревание водорослей и сбор `RawAlgae`.
