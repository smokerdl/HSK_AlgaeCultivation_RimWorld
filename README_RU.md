# HSK Algae Cultivation — RimWorld 1.5 / 1.6

Аддон для Hardcore SK, добавляющий отдельную зону **«Водорослевое хозяйство»** для существующей культуры HSK `PlantAlgae`.

## Что добавляет

Зона предназначена только для водорослей и поддерживает автоматический и принудительный посев, а также сбор урожая. Её можно рисовать на следующих типах местности:

- `WaterShallow` — мелководье;
- `WaterMovingShallow` — мелководье с течением;
- `WaterMovingChestDeep` — вода глубиной по грудь с течением;
- `Marsh` — болото.

Глубокая вода не поддерживается.

## Установка для игрока

Предварительно собранные DLL для RimWorld 1.5 и 1.6 уже включены в репозиторий. **Для обычной установки ничего собирать не нужно.**

1. Скачай архив репозитория через **Code → Download ZIP** на GitHub.
2. Распакуй папку мода в `RimWorld\Mods\` (например, в `RimWorld\Mods\HSK_AlgaeCultivation_RimWorld`).
3. Включи Hardcore SK и HSK Algae Cultivation в списке модов. Harmony должен быть установлен в составе твоего набора модов.
4. Запусти игру и выбери меню «Зоны» → «Водорослевое хозяйство».

Не переименовывай и не смешивай содержимое папок `1.5` и `1.6`: игра выбирает файлы для своей версии из соответствующей папки.

## SeedsPlease

`SeedsPlease` — **необязательная** интеграция. Если активен мод с package ID `notfood.seedsplease`, аддон добавляет семена водорослей, которые используются при посеве. Без SeedsPlease зона продолжает работать без семенной механики.

## Сборка из исходников

Сборка нужна только при изменении кода. Используй DLL и библиотеки именно той версии RimWorld, для которой собираешь мод.

Для установки RimWorld/HSK 1.6 в `D:\Games\RimWorld`, открой CMD в корне репозитория и выполни:

```cmd
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Для версии 1.5 укажи `set RIMWORLD_VERSION=1.5`. Если переменная версии не задана, сборка по умолчанию выполняется для 1.5. Если скрипт не находит нужный `0Harmony.dll`, можно задать полный путь к нему через переменную `HARMONY_PATH`.

Сборка создаёт DLL в `1.5\Assemblies\` или `1.6\Assemblies\` соответственно. После изменения кода проверь сборку в игре перед публикацией обновлённой DLL.

## Проверка после изменений

1. Убедись, что зона отображается в меню «Зоны» и её можно редактировать и удалять.
2. Проверь автоматический посев и принудительный посев при наличии семян (если используется SeedsPlease).
3. Дождись созревания водорослей и проверь автоматический и принудительный сбор урожая.
4. Проверь журнал игры на ошибки XML-патчей и Harmony.

XML-проверки в репозитории запускаются GitHub Actions. Они проверяют корректность XML и согласованность файлов/переводов для обеих поддерживаемых версий, но не заменяют запуск игры.
