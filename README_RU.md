# HSK Algae Cultivation — эксперимент с водяной лилией для RimWorld 1.6

Аддон для Hardcore SK (HSK). Эта экспериментальная ветка добавляет растение «Водяная лилия» в водную зону, чтобы проверить, почему стандартный селектор RimWorld не показывает HSK `PlantAlgae`.

**Версия 1.5 заморожена:** её файлы и готовая DLL сохранены в прежнем состоянии. Новые функции и тестирование разрабатываются только для RimWorld 1.6.

## Что проверяет экспериментальная ветка

- Специальную зону для поддерживаемой водной и болотистой местности.
- Поддержку двух культур в этой зоне: существующих водорослей HSK `PlantAlgae` и нового тестового растения `Plant_WaterLily`.
- Использование стандартного селектора культур RimWorld вместо собственного меню. Это позволяет сравнить оба растения при одинаковой логике выбора.
- Водяная лилия наследует базовое определение цветка HSK и имеет красоту `Beauty=15` и `BeautyOutdoors=15`. На время теста используется текстура белой розы HSK.
- Необязательные определения семян для SeedsPlease: водорослей и водяной лилии.
- Автоматический и принудительный посев через специальные обработчики работы водной зоны.

## Установка и тестирование

1. Для эксперимента используй ветку `experiment/water-lily-standard-selector`, а не `main`.
2. Установи мод в `RimWorld\Mods\` и включи Hardcore SK, HSK Algae Cultivation и Harmony; SeedsPlease нужен только для проверки семян.
3. В RimWorld 1.6 создай водную зону на поддерживаемой водной или болотистой местности.
4. Открой селектор культур и проверь, показывает ли он **водяную лилию**, **водоросли**, оба растения или ни одного.
5. Если селектор работает, отдельно проверь посев, рост, параметры красоты и SeedsPlease. Наличие культуры в списке ещё не доказывает, что она будет расти на любом типе поддерживаемой местности.
6. Проверь журнал игры на ошибки XML и Harmony.

Не смешивай содержимое папок `1.5` и `1.6`: сборка 1.5 остаётся замороженной. Текстура водяной лилии временная — позже её нужно заменить собственным ассетом.

## Сборка для RimWorld 1.6

Открой CMD в корне репозитория и выполни:

```cmd
cd /d C:\Dev\HSK_AlgaeCultivation_RimWorld
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Если сборка прошла успешно, скопируй содержимое папки `1.6` в установленный мод и перезапусти игру. Не пересобирай папку `1.5`, если нужно сохранить её как legacy-снимок.

GitHub Actions проверяет синтаксис XML и обязательные файлы, но не заменяет локальную сборку C# и игровой тест.
