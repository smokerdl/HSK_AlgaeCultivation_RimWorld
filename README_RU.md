# HSK Algae Cultivation — RimWorld 1.5

Первая альфа-версия аддона для Hardcore SK.

## Что добавляет

Новая зона **«Водорослевое хозяйство»**. Она создаётся через меню **Зоны** и предназначена только для `PlantAlgae` из Hardcore SK.

На первой альфа-версии зону можно рисовать на:

- `WaterShallow` — мелководье
- `WaterMovingShallow` — подвижное мелководье
- `WaterMovingChestDeep` — подвижная вода по грудь
- `Marsh` — болото

Глубокая вода пока намеренно не добавляется.

## SeedsPlease

`SeedsPlease` — **необязательная** зависимость.

Если `notfood.seedsplease` включён, мод добавляет `Seed_Algae` через `MayRequire`, поэтому без SeedsPlease этот Def вообще не используется.

Если SeedsPlease выключен, зона продолжает работать и выращивает водоросли без семян.

## Установка

Папку `HSKAlgaeCultivation` положить в:

`RimWorld\Mods\`

Затем собрать DLL:

`Source\Build.bat`

Скрипт автоматически ищет RimWorld относительно расположения мода (для обычной Steam-установки вида `SteamLibrary\steamapps\common\RimWorld\Mods\...`). При необходимости можно задать:

`$env:RIMWORLD_DIR = 'C:\SteamLibrary\steamapps\common\RimWorld'`

## Первый тест

1. Включить Hardcore SK.
2. Включить HSK Algae Cultivation.
3. Включить SeedsPlease для проверки семенной интеграции.
4. Создать новую карту.
5. В меню «Зоны» выбрать «Водорослевое хозяйство».
6. Нарисовать зону на мелководье.
7. Выбрать водоросли — для текущей версии зона ограничена только `PlantAlgae`.
8. Проверить посадку и рост.
9. Проверить сбор `RawAlgae`.

Это первая альфа: пока мы не меняем существующую механику дикорастущих водорослей и не трогаем их генерацию на карте.
