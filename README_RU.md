# HSK Algae Cultivation — эксперимент с водяной лилией для RimWorld 1.6

Аддон для Hardcore SK (HSK). Эта экспериментальная ветка добавляет растение «Водяная лилия» в водную зону, чтобы проверить стандартный селектор RimWorld и логику очистки клеток перед посевом.

**Версия 1.5 заморожена:** её файлы и готовая DLL сохранены в прежнем состоянии. Новые функции и тестирование разрабатываются только для RimWorld 1.6.

## Что проверяет экспериментальная ветка

- Специальную зону для поддерживаемой водной и болотистой местности.
- Поддержку двух культур: водорослей HSK `PlantAlgae` и тестового растения `Plant_WaterLily`.
- Использование стандартного селектора культур RimWorld вместо собственного меню.
- Водяная лилия наследует базовое определение цветка HSK и имеет `Beauty=15` и `BeautyOutdoors=15`. Пока используется текстура белой розы HSK.
- Необязательные определения семян для SeedsPlease.
- Автоматический и принудительный посев, удаление неподходящих растений и сбор выбранной культуры через обработчики водной зоны.

## Ожидаемое поведение при посеве

- Если в клетке уже растёт выбранная культура, колонист оставляет её на месте. Например, существующие дикие водоросли не должны вырубаться и высаживаться заново, если выбраны водоросли.
- Если в клетке растёт другое растение, колонист сначала получает задание срезать его, а затем на следующем проходе может посадить выбранную культуру. Для автоматической очистки должны быть включены **Allow Sowing / Разрешить посев** и **Allow Cutting / Разрешить срезание**.
- Если Allow Cutting выключен, колонист не должен срезать неподходящее растение и не должен сажать поверх него.
- Предметы и сооружения, блокирующие посадку, обрабатываются отдельно: предметы, которые можно переносить, могут быть отодвинуты в сторону, а неперемещаемые препятствия не дают посадить культуру.
- Если включён SeedsPlease, по результату текущего игрового теста нужные семена должны физически присутствовать на карте, чтобы культура появилась в селекторе. Для проверки селектора сначала положи на карту семена водорослей и/или водяной лилии.

Это поведение пока требует проверки в игре после сборки.

## Установка и тестирование

1. Для эксперимента используй ветку `experiment/water-lily-standard-selector`, а не `main`.
2. Установи мод в `RimWorld\Mods\` и включи Hardcore SK, HSK Algae Cultivation и Harmony; SeedsPlease нужен для проверки семян.
3. В RimWorld 1.6 создай водную зону на поддерживаемой местности.
4. Проверь селектор при наличии семян на карте.
5. Для проверки очистки выдели зону, выбери водоросли и проследи за клетками с: (а) дикими водорослями, (б) водяными лилиями, (в) тростником из Odyssey или другим растением, (г) предметом, который можно переносить.
6. Повтори тест при включённых Allow Sowing и Allow Cutting, а затем с выключенным Allow Cutting.
7. Переключи культуру с лилии на водоросли в клетке, где уже растёт водоросль, и убедись, что колонист её сохраняет.
8. Проверь журнал игры на ошибки XML и Harmony.

Не смешивай содержимое папок `1.5` и `1.6`: сборка 1.5 остаётся замороженной. Текстура водяной лилии временная — позже её нужно заменить собственным ассетом.

## Сборка для RimWorld 1.6

Открой CMD в корне репозитория и выполни:

```cmd
cd /d C:\Dev\HSK_AlgaeCultivation_RimWorld
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Если сборка прошла успешно, скопируй содержимое папки `1.6` в установленный мод и полностью перезапусти игру. Не пересобирай папку `1.5`, если нужно сохранить её как legacy-снимок.

GitHub Actions проверяет синтаксис XML и обязательные файлы, но не заменяет локальную сборку C# и игровой тест.
