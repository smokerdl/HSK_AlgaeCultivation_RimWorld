# HSK Algae Cultivation — RimWorld 1.6 и legacy-сборка 1.5

Аддон для Hardcore SK (HSK). Активная версия для RimWorld 1.6 добавляет специализированную зону **«Водная плантация»** для выращивания существующих водорослей HSK (PlantAlgae).

**Версия 1.5 заморожена:** её файлы и готовая DLL сохранены в прежнем состоянии. Новые функции, сборка и тестирование разрабатываются только для RimWorld 1.6.

## Что добавляет активная версия 1.6

- Создание водной плантации на поддерживаемых водных и болотистых клетках.
- Селектор культуры, в котором явно доступна культура HSK «Водоросли» (PlantAlgae). Пока это единственная поддерживаемая культура.
- Автоматический и принудительный посев, сбор урожая и сохранение выбранной культуры.
- Использование существующего определения водорослей HSK: аддон не заменяет их графику или продукт сбора.
- Необязательная интеграция с SeedsPlease и предметом семян водорослей (Seed_Algae).

Зона сохраняет прежний внутренний класс Zone_GrowingAlgae, чтобы старые сохранения продолжали загружаться. Для сохранений до появления поля выбранной культуры значение по умолчанию — водоросли.

## Установка

1. Скачай архив репозитория через **Code → Download ZIP** на GitHub.
2. Распакуй папку мода в RimWorld\Mods\.
3. Включи Hardcore SK и HSK Algae Cultivation в списке модов. Harmony должен быть установлен в составе твоего набора модов.
4. В RimWorld 1.6 выбери меню «Зоны» → «Водная плантация» на поддерживаемых водных или болотистых клетках.

Не переименовывай и не смешивай содержимое папок 1.5 и 1.6: игра выбирает файлы соответствующей версии. Содержимое 1.5 сохранено как прежняя сборка и не будет получать новые функции.

SeedsPlease — **необязательная** интеграция. Если активен мод с package ID notfood.seedsplease, аддон добавляет предмет семян водорослей. Без SeedsPlease зона работает без семенной механики.

## Сборка для RimWorld 1.6

Сборка нужна только при изменении кода. Для активной версии используй DLL и библиотеки RimWorld 1.6.

Открой CMD в корне репозитория и выполни:

~~~cmd
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
~~~

Если скрипт не находит нужный 0Harmony.dll, можно задать полный путь к нему через переменную HARMONY_PATH. Если RIMWORLD_VERSION не задана, сборка по умолчанию выполняется для версии 1.6.

Сборка создаёт DLL в 1.6\Assemblies\HSKAlgaeCultivation.dll. После изменения кода проверь сборку в игре перед публикацией обновлённой DLL. Прежнюю DLL для версии 1.5 не пересобирай, если нужно сохранить текущую legacy-сборку.

## Проверка после изменений

1. Убедись, что зона отображается в меню «Зоны» и её можно редактировать и удалять.
2. Открой селектор культуры и убедись, что в нём присутствуют водоросли.
3. Проверь автоматический и принудительный посев на подходящей местности.
4. При активном SeedsPlease проверь Seed_Algae, включая отображение информации о предмете.
5. Дождись созревания растения и проверь автоматический и принудительный сбор урожая.
6. Проверь журнал игры на ошибки XML-патчей и Harmony.

GitHub Actions проверяет корректность XML и ключи переводов, но эти проверки не заменяют сборку и запуск игры.
