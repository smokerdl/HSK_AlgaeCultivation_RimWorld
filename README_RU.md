# HSK Algae Cultivation — RimWorld 1.6

Аддон для Hardcore SK (HSK), добавляющий специальную зону **«Водорослевое хозяйство»** для выращивания водорослей и новых водных растений в RimWorld 1.6.

**Поддерживаемые версии:** активная разработка ведётся для RimWorld 1.6. Папка и DLL версии 1.5 сохранены как замороженная legacy-версия и не обновляются.

## Возможности

- Зона «Водорослевое хозяйство» для поддерживаемых типов водной и болотистой местности.
- Три растения: водоросли HSK `PlantAlgae`, декоративная водяная лилия `Plant_WaterLily` и светокамыш `Plant_Glowreed`.
- Стандартный селектор культур RimWorld. Если включён SeedsPlease, соответствующие предметы семян должны физически присутствовать на карте, чтобы культура появилась в селекторе.
- Водяная лилия имеет `Beauty=15` и `BeautyOutdoors=15`, использует собственные текстуры мода и не собирается при созревании.
- Светокамыш накапливает энергию при дневном свете, если растёт под открытым небом, а ночью слабо светится. Яркость и радиус свечения зависят от роста растения. Светокамыш декоративный и не собирается.
- Необязательная интеграция SeedsPlease с определениями семян для водорослей, водяной лилии и светокамыша.
- Посев и сбор водорослей с очисткой клеток с учётом выбранной культуры; декоративные водяная лилия и светокамыш исключены из заданий сбора урожая.

## Очистка клеток и посев

- Если в клетке уже растёт выбранная культура, колонист оставляет растение на месте. Например, дикие водоросли сохраняются, если выбраны водоросли.
- Если в клетке находится другое растение, колонист сначала получает задание `CutPlant`. Посев может произойти на следующем проходе работы. Для автоматической очистки должны быть включены **Allow Sowing / Разрешить посев** и **Allow Cutting / Разрешить срезание**.
- Если **Allow Cutting / Разрешить срезание** выключен, колонист не должен срезать неподходящее растение или высаживать культуру поверх него.
- Другие препятствия обрабатываются отдельно: предметы, которые можно переносить, могут быть отодвинуты, а неподвижные препятствия блокируют посев.

## Установка

1. Скачай архив через **Code → Download ZIP**.
2. Распакуй папку мода в `RimWorld\Mods\`.
3. Включи Hardcore SK, HSK Algae Cultivation и Harmony. SeedsPlease необязателен.
4. В RimWorld 1.6 выбери **«Зоны» → «Водорослевое хозяйство»**.

Не смешивай содержимое папок `1.5` и `1.6`. Файлы версии 1.5 сохранены для совместимости со старой сборкой и не обновляются.

## Сборка для RimWorld 1.6

Открой CMD в корне репозитория и выполни:

```cmd
cd /d C:\Dev\HSK_AlgaeCultivation_RimWorld
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Скрипт собирает DLL для RimWorld 1.6. Для актуального рабочего релиза важно включать в коммит и исходный код, и соответствующую пересобранную DLL. GitHub Actions проверяет XML, обязательные файлы и ключи переводов, но не компилирует C# и не запускает игру.
