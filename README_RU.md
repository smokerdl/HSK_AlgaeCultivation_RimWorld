# HSK Algae Cultivation — RimWorld 1.6 и legacy-сборка 1.5

Аддон для Hardcore SK (HSK). Активная версия для RimWorld 1.6 добавляет универсальную зону **«Водная плантация»** для выращивания водорослей HSK и тростника из Odyssey.

**Версия 1.5 заморожена:** её файлы и готовая DLL сохранены в прежнем состоянии. Новые функции, сборка и тестирование разрабатываются только для RimWorld 1.6 с включённым DLC Odyssey.

## Что добавляет активная версия 1.6

- Универсальную зону для поддерживаемой водной и болотистой местности.
- Выбор культуры в настройках зоны: водоросли HSK `PlantAlgae` или тростник Odyssey `Plant_Reeds`.
- Автоматический и принудительный посев, а также сбор урожая поддерживаемых культур.
- Необязательную интеграцию с SeedsPlease, включая семена водорослей и тростника.

Зона сохраняет прежний внутренний класс `Zone_GrowingAlgae`, чтобы старые сохранения продолжали загружаться. Для существующих сохранений, созданных до появления выбора культуры, по умолчанию выбираются водоросли.

## Установка

1. Скачай архив репозитория через **Code → Download ZIP** на GitHub.
2. Распакуй папку мода в `RimWorld\Mods\`.
3. Включи Hardcore SK и HSK Algae Cultivation в списке модов. Harmony должен быть установлен в составе твоего набора модов.
4. В RimWorld 1.6 с включённым Odyssey выбери меню «Зоны» → «Водная плантация».

Не переименовывай и не смешивай содержимое папок `1.5` и `1.6`: игра выбирает файлы соответствующей версии. Содержимое 1.5 сохранено как прежняя сборка и не будет получать новые функции.

SeedsPlease — **необязательная** интеграция. Если активен мод с package ID `notfood.seedsplease`, аддон добавляет семена поддерживаемых водных культур. Без SeedsPlease зона работает без семенной механики.

## Сборка для RimWorld 1.6

Сборка нужна только при изменении кода. Для активной версии используй DLL и библиотеки RimWorld 1.6.

Открой CMD в корне репозитория и выполни:

```cmd
set RIMWORLD_DIR=D:\Games\RimWorld
set RIMWORLD_VERSION=1.6
Source\Build.bat
```

Если скрипт не находит нужный `0Harmony.dll`, можно задать полный путь к нему через переменную `HARMONY_PATH`. Если `RIMWORLD_VERSION` не задана, сборка по умолчанию выполняется для версии 1.6.

Сборка создаёт DLL в `1.6\Assemblies\HSKAlgaeCultivation.dll`. После изменения кода проверь сборку в игре перед публикацией обновлённой DLL. Прежнюю DLL для версии 1.5 не пересобирай, если нужно сохранить текущую legacy-сборку.

## Проверка после изменений

1. Убедись, что зона отображается в меню «Зоны» и её можно редактировать и удалять.
2. Проверь, что селектор позволяет выбрать только водоросли и тростник.
3. Проверь автоматический и принудительный посев каждой культуры на подходящей местности; если используется SeedsPlease, проверь наличие требуемых семян.
4. Дождись созревания растений и проверь автоматический и принудительный сбор урожая.
5. Сохрани игру с выбранным тростником, перезагрузи сохранение и убедись, что выбор сохранился. Отдельно проверь старое сохранение с водорослями.
6. Проверь журнал игры на ошибки XML-патчей и Harmony.

GitHub Actions проверяет корректность XML и ключи переводов, но эти проверки не заменяют сборку и запуск игры.
